Requirements
    Python 3.x
    No external libraries required (uses only built-in csv and os modules)

Features
    Add new expenses with details:
        Date (YYYY-MM-DD)
        Category (e.g., Food, Travel, Health, etc.)
        Amount
        Description
    View all recorded expenses in a neatly formatted table.
    Track monthly budget and see how much is left or if you are over budget.
    Save expenses to a CSV file (expenses_saved.csv) for persistent storage.
    Detect and display missing fields in expense records.
